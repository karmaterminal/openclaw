## Agent-elected turn continuation

OpenClaw sessions can elect another turn with `continue_work`, dispatch bounded background work with `continue_delegate` (normal, silent, silent-wake, or post-compaction return), and request compaction after preserving working state with `request_compaction`. The feature is opt-in and bounded by chain length, delegate width, delay, and cost limits. This is core lifecycle functionality, not a prompt-only skill: the gateway and agent runtime own turn finalization, durable election, restart replay, child admission and return, and the compaction seam. [Design and custody revision](https://github.com/karmaterminal/openclaw/blob/08fead65d21e915b4f0b72c2f9c02f7dac7ad53d/docs/design/continue-work-signal-v2.md).
