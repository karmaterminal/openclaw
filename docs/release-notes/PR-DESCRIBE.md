Canonical2 moves continuation onto a TaskFlow-backed delegate substrate, preserves one-cycle legacy `taskFlowDelegates` config tolerance, and adds durability proof for the chain state that rides alongside those delegates. The audit lane fixed durable write-back after ordinary tool-delegate dispatch (PR #427, `d0f31f65cc1250e5300d1c45ac4feeda71100b18`), followup-token advancement when `dispatched === 0` (PR #428, `e73fd0f088813ca125bab60a2cc54c08ac97ff07`), child-drain persistence after subagents return (PR #429, `dc572c01062a8da9a337039c87c1eb09288af640`), and the #431 followup disk-orphan by wrapping persistence in `updateSessionStore` (PR #432, `cf7830ffb3702bf7d826d70838893e2e41709f12`). The swim-37 durability harness (PR #430, `15e045fe460f0fa00f14fdf29f95627d7200b789`) now covers two-hop, followup-token, and restart roundtrips. Remaining pre-squash review decisions are open PR #368, #361, and #363.
